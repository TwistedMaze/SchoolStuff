# O que é um mapa mental?

<div class="mt-8 mx-auto max-w-5xl">
  <p class="text-2xl leading-relaxed">Organiza a informação a partir de uma <strong>ideia central</strong>.</p>
  <p class="mt-6 text-xl leading-relaxed">As ideias relacionadas ficam à volta e vão do <strong>geral para o específico</strong>.</p>
</div>

```text

         [ CAUSAS ] [ EXEMPLOS ] [ PROTEÇÃO ]
             |          |            |
       Desflorestação  Tigre       Reservas
       Poluição        Panda       Leis
```
