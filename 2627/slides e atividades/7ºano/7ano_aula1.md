## Sistemas Operativos

---
### O que é um Sistema Operativo?

- É o **cérebro invisível** do computador.
- Controla tudo o que acontece entre o **hardware** e o **utilizador**.
- Sem ele, o computador seria apenas um conjunto de peças.

---

### Kernel — o coração do sistema

- O **kernel** ( **núcleo**) é a parte central do sistema operativo.
- Fala diretamente com o **hardware** (CPU, memória, disco).
- Decide **quem usa o quê** e **quando**.
- É como o “professor” que distribui tarefas aos “alunos” (os programas).

---

## Interface — a parte que vemos

### Interface Gráfica (GUI)
- Usa **janelas, ícones e menus**.
- Ideal para utilizadores iniciantes.
- mais acessivel, menos controlo
---

### Interface de Texto (CLI)
- Usa **comandos escritos**.
- Exemplo: Terminal Linux, PowerShell.
- Ideal para programadores e técnicos.

## Tipos de Sistemas Operativos

- Para computadores – Windows, Linux, macOS

- Para dispositivos móveis – Android, iOS

- Para outros dispositivos – sistemas usados em carros, televisores, relógios, máquinas, etc.
